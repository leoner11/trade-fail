## 3. NON-NEGOTIABLE RULES (inherited, unchanged)

1. LLM never does arithmetic — calc computes; digit guards enforce.
2. Uncomputable → escalate with gaps, never guess. (Digest/memo/brief
   variants: cite-or-reject — [I<id>]/[L<n>]/spine-row citations.)
3. Always-human list sacred at every autonomy level.
4. OSS repos stay whole; HTTP-only integration. (postiz dist patches remain
   the one documented exception.)
5. Client variation lives in DATA + .env — never code forks.
6. Config-as-code: agents/manifest.json, feeds.json, DSLs, compose, rules.
7. .env holds secrets. Never print/commit keys.
8. `env -u PYTHONPATH calc/.venv/bin/python` discipline for every run.
9. NEW — execution is gated, data never: a disabled agent 403s honestly;
   spine is untouched by entitlement state.
10. NEW — roadmap ≠ menu: an agent enters agents/manifest.json as
    `available` ONLY when its gate exists and is green.
