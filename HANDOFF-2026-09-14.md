## 4. NEW TRAPS (numbered in docs/spike-log.md session #17 entry)

- **#50 — entitlement LICENSE_SECRET reads `os.environ` ONLY.** glue's
  `cfg()` falls back to the repo `.env`, but `entitlement._env_secret()`
  does not — a host-run uvicorn without the exported secret silently
  verify-fails → mode falls back to `open` (back-compat) even with a
  valid license.json present. Symptom during the drill: "licensed: false".
  Fix for drills: restart glue with `LICENSE_SECRET=$(cat …)` in env
  (watch trailing newline when echoing from a file). Client boxes are
  fine via compose `env_file`. Consider fail-closed while touching it
  (security backlog #4).
- **#51 — gate live-checks that `except → print skipped` can hide
  born-dead endpoints.** intel/digest 500'd from birth yet its gate was
  10/10 for a week because the live check skipped instead of failing.
  Rule: when the endpoint is expected up, a failed live check must FAIL
  the gate, not skip.
- Minor: vite dev binds IPv6 `[::1]:5173` only — IPv4-only port probes
  false-negative; `curl localhost` is fine.
